# Strona Psychologa

Profesjonalna strona internetowa dla gabinetu psychologicznego.

## Struktura projektu

```
psychologist-website/
├── index.html              # Strona główna
├── polityka-cookies.html   # Polityka cookies
├── style.css               # Style CSS
├── script.js               # Skrypty JavaScript
├── generate_logo.py        # Skrypt do generowania logo
└── README.md              # Ten plik
```

## Technologie

- HTML5
- CSS3
- JavaScript
- Python (do generowania logo)

## Uruchomienie

1. Otwórz plik `index.html` w przeglądarce internetowej
2. Lub uruchom lokalny serwer HTTP:
   ```bash
   python -m http.server 8000
   ```
   Następnie otwórz przeglądarkę pod adresem `http://localhost:8000`

## Generowanie logo

Aby wygenerować logo, uruchom:
```bash
python generate_logo.py
```
